## โปรเจคนี้เป็นส่วนหนึ่งของวิชาวิศวกรรมซอฟต์แวร์
# รหัสวิชา BSCCS304 (ภาคการศึกษามี่ 1/69)

# ฟีเจอร์การทำงาน (Features)
1. เครื่องคิดเลขนี้ทำงานผ่าน commandline (Terminal)
2. มีฟังก์ชันทางคณิตศาสตร์เบื้องต้นและขั้นสูงดังนี้ :
 - + บวก (Addition)
 - - ลบ (Subtraction)
 - * คูณ (Multiplication)
 - / หาร (Division)
